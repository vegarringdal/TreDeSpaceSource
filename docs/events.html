Drive the viewer from your app

The viewer is embedded as an <iframe> and controlled with postMessage: every command gets exactly one typed response. Copy the dependency-free SDK below and call one method per command — no envelopes by hand. The command reference further down is generated from that SDK, so it never drifts.

The SDK

tredespace-client.ts

Dependency-free, fully typed. Copy it into your host app — it handles correlation ids, the ready handshake, timeouts, and transferables. One method per command.

View raw 
// host side — one client per embedded viewer
import { TredespaceClient } from './tredespace-client';

const client = new TredespaceClient(iframe, { targetOrigin: 'https://tredespace.com' });
await client.ready();
await client.selectionSet(['/SITE/ZONE-1/PIPE-401']);
client.onTreeSelect((e) => syncMyGrid(e.fullnames));

How it works

Four things to know

Request / response
Every command gets exactly one reply with the same id — success or a typed error. No fire-and-forget.
Versioned envelope
Both directions carry tredespace: 1 so host and viewer can evolve without guessing.
Origin allowlist
Messages are dropped unless the sender origin is allowed (settings, embedded panels, or ?apiOrigins=). Replies target the sender, never *.
JSON + transferables
Payloads are JSON; file bytes ride as ArrayBuffer transferables (zero-copy), chunked past 500 MB.
