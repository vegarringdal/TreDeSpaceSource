App layout · F7

The External layout

An external app is a web page from somewhere else that opens inside TreDeSpace: a tag report, a document lookup, a project selector, your company's own tools. Each one gets a button on the External ribbon. Some of these tools are built to work together with the viewer, for example to select or colour items in the model, or to show details for what you select.

Press F7 (or pick External on the App Layout ribbon) to show the External ribbon with the model tree and the 3D view.

  1. External ribbon — one button per app, described below.
  2. Hierarchy — the model tree.
  3. 3D view.
  4. Console — minimised. Click its tab to see messages.

Which buttons you see depends on how TreDeSpace is set up for you. Apps are added under Settings → External (see below), by whoever set up TreDeSpace for you or by yourself. When TreDeSpace is built into your company's own web page, that page can add them too. If nothing is set up, the ribbon only shows a greyed-out Configure… button.

Ribbon

The External ribbon

  1. A big button — click it to open the app.
  2. A smaller button — apps can have big, medium or small buttons; it makes no difference to how they work.
  3. Another button in the same group — this one opens in a new browser tab.
  4. The group name — apps are grouped by topic. Apps without a group are under External Apps.

Hold the mouse over a button to see what it opens. If your administrator wrote no description, the tooltip shows the web address and how the app opens: as a panel, in a new browser tab or as a modal dialog.

How an app opens

  • As a panel (the usual way) — the app opens as a tab on the right side of the screen, like any other panel. Drag its tab to move it, drag the edge to make it wider, and close it with the ✕ on its tab. Closing the panel closes the app; opening it again starts it fresh. Most apps open one panel only: clicking the button again brings that panel back. Some are set up to open a new panel per click, so you can have several side by side.
  • As a dialog — the app opens in a window in the middle of the screen, over the model. Drag its title bar to move it, drag the bottom-right corner to resize it, and close it with ✕. TreDeSpace's own messages (loading, errors, questions) still appear on top of it.
  • In a new browser tab — the app opens next to TreDeSpace in your browser. Tools that work with the viewer still do so from that tab.

Apps on the Home ribbon

An app you need all the time, such as a project selector, can be put on the Home ribbon instead, so it is there as soon as TreDeSpace starts. It then sits at the start (left) or the end (right) of the Home ribbon, in its own group, and no longer shows on the External ribbon.

An app can also be set to open by itself when TreDeSpace starts, as a panel or a dialog.

Settings

Where apps are set up

Apps are added and changed under Settings → External. Click Add external app, fill in at least a name and a web address, and the button appears on the ribbon. The full set of options is described in the Settings guide; the ones that change what you see are:

  1. Button name — the text on the button, and the panel's title.
  2. Web address — the page that opens.
  3. Section — the ribbon group the button goes in. Next to it: the button size.
  4. Multiple instances — a new panel per click, instead of one.
  5. New window — opens in a new browser tab instead of a panel.
  6. Modal dialog — opens as a dialog over the app.
  7. Show in Home — puts the button on the Home ribbon instead; a list next to it picks the start or the end.
  8. Open on start — opens the app by itself when TreDeSpace starts (not for apps that open in a new browser tab).

The two text boxes in the middle hold the button's tooltip and optional settings passed to the app. The Sandbox and Permissions boxes control what the app's page is allowed to do in your browser (open pop-ups, use the camera, …); all are off unless your administrator ticks them.

  • Apps are kept in your browser, so they are still there next time. Reset all settings does not remove them; Reset external apps on the same tab does.
  • When TreDeSpace is built into another web page, that page can add its own app buttons for the session. Those are not listed under Settings and can't be changed there.
