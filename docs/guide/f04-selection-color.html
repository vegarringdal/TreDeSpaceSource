App layout · F4

The Selection Color layout

Press F4 (or pick Selection Color on the App Layout ribbon) to switch to the colouring workspace. Everything on its ribbon works on the current selection: select items in the tree or the 3D view, then colour, ghost or hide them. For colouring by name, with rules you can save and reuse, the Set Color panel opens on the right.

  1. Selection Color ribbon — described group by group below.
  2. Hierarchy — the model tree. Click a row to select that item and everything under it.
  3. 3D view — click an item to select it. Ctrl + click adds an item to the selection, or takes it out again. Clicking empty space unselects everything.
  4. Set Color — colour by name with rules. See the Set Color guide.
  5. Console — minimised. Click its tab to see messages, for example how many items an action changed.

Ribbon

The Selection Color ribbon

Most buttons are greyed out until something is selected. Every change here can be undone with Undo (PAGEUP).

Hidden Items

  1. Hide (H) — hides the selected items.
  2. Unhide Sel (J) — shows the selected items again (select them in the tree, since they can't be clicked in 3D).
  3. Unhide All — shows every hidden item.
  4. Unhide Box — shows everything that touches the clipping box, wherever the box is now (it does not have to be switched on). See F3 Clip Box.
  5. Unhide Sel+Off. — shows everything around the selection: inside its bounding box, grown on every side by the Fit Sel offset from the Clipping Box ribbon.
  6. Unhide Each+Off. — the same, but around each selected item on its own. Better for scattered items, where one big box would show too much. Works with up to 200 selected items.

Clipping Shape Select

Select Inside selects every item that lies completely inside the clipping box or an enabled clip shape. Select Intersecting also takes the items that only touch it. Both are greyed out while clipping is off. Set up the box or shapes in F3 Clip Box first.

Quick Coloring

  1. Colour swatches — click one to colour the selection. Each swatch has a shortcut (ALT 210 for the first, and up).
  2. Reset Sel — puts the selection back to its original colour.
  3. Reset All — removes every colour change on the model.
  4. Panel — opens the Color Panel on the left. Use it to pick any colour, or to change which colours the swatches hold.

Opacity Override

  1. The value in percent: 100 % is solid, lower is more see-through. Use − / + or type a number.
  2. Set Sel — gives the selection that opacity.
  3. Reset Sel — makes the selection solid again.
  4. Reset All (Y) — removes every opacity change.

Misc, Reset and History

  1. Invert Sel (I) — selects everything that is not selected, and unselects the rest.
  2. Isolate (ALT+H) — hides everything except the selection.
  3. Clear Sel (ESC) — unselects everything.
  4. Clear All (ALT+R) — puts the whole model back to normal: all colours, opacity and hiding are removed.
  5. Undo (PAGEUP) — undoes the last colour, opacity, hide or unhide change.
  6. Redo (PAGEDOWN) — does it again.

Step by step

Common tasks

Colour a system

  1. Select it: click its row in the Hierarchy (here /HA-PIPE), or click it in the 3D view.
  2. Click a swatch under Quick Coloring. Click in empty space or press ESC to unselect and see the colour without the selection highlight.

Make something see-through

  1. Select it, here the mechanical model /HA-MECH.
  2. Set the Opacity Override value to 20 % and press Set Sel. What is behind it shows through.
  3. To make it solid again, select it and press Reset Sel. To undo every opacity change, press Reset All (Y).

Look at one system on its own

  1. Select it, here the safety model /HA-SAFE.
  2. Press Isolate (ALT+H). Everything else is hidden.
  3. To bring the rest back, press Unhide All, or Clear All (ALT+R) to also remove colour and opacity changes.

Show what is around a hidden area

After Isolate, you sometimes want to see what is next to the item as well. Select it and press Unhide Sel+Off.: everything within the Fit Sel offset of its bounding box comes back (the offset is set on the Clipping Box ribbon). For several items far apart, use Unhide Each+Off. instead.

Panel

Set Color (right side)
