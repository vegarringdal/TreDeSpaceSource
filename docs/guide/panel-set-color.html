Set Color

Set Color colours, ghosts or hides many parts of the model at once, by name. Write a short list of rules ("everything whose name contains HA-PIPE → orange") and press Run. Rules can be saved to a file and reused on any model with the same naming.

To colour a few items you have already selected, the Selection Color ribbon is quicker. Use Set Color when the items are found by their names or when you want the result again later.

Open the panel

Press F4: the Selection Color layout has Set Color on the right. To open just the panel, open the Panel tab of the ribbon 1 and click Set Color 2, or press CTRL+C.

A tour of the panel

  1. Run mode — what happens to the model before the rules run (see Run modes).
  2. + Rule — adds an empty rule at the bottom of the list.
  3. Run — applies every rule that is switched On, from top to bottom.
  4. Save — downloads the whole rule set (mode and rules) as a .json file.
  5. Load — replaces the rules with a saved file.
  6. Delete all — removes every rule. The run mode is kept.
  7. Reset all — puts the model back to normal: every colour and opacity change is undone and hidden items come back. Your rules are kept.
  8. A rule, folded. Click its title to open it. The header shows how many items the last run changed, and has buttons to insert a rule above, move it up or down, and switch it On / Off.
  9. A filter row — decides which names the rule picks up. A rule can have several.

How rules work

  • Rules run from top to bottom. When two rules match the same item, the lower one wins: it sets both the colour and the opacity of that item.
  • A rule with colour Default and opacity 1 puts its items back to how they look in the model.
  • An empty Value matches everything. That is handy for a first "ghost everything" rule.
  • Matching ignores upper and lower case.
  • The rules are not kept when you reload the page. Use Save to keep them.

Colour one system

Colour all piping orange.

  1. Open the panel. It starts with one empty rule, #1 Rule. Give the rule a name 1. Click Custom 2, then click the colour 3 to pick a different one.
  2. In the filter row, type the text to look for in Value 1. Leave the match type on Contains 2. Set the level to Lvl 2 3, so only names at the second level of the tree are tested. In the sample, level 1 is the Huldra folder and level 2 holds the discipline models (/HA-PIPE, /HA-SAFE …). A match always takes everything below it in the tree.
  3. Press Run 1, or ALT 1021. The rule header shows how many items were coloured 2. If it says 0 matched, check the spelling and the level.

Highlight systems and ghost the rest

Because the lower rule wins, you can start with a rule that matches everything and then "paint over" it.

  1. Rule #1 Ghost everything: leave Value empty, keep the colour on Default and set Opacity to 0.15. It matches every item 1.
  2. Add #2 Piping (contains HA-PIPE, Lvl 2, orange) and #3 Safety (contains HA-SAFE, Lvl 2, red). Both keep opacity 1, so their items become solid again.
  3. Press Run. Use the arrows 2 to change the order, and On / Off 3 to leave a rule out without deleting it.

Run modes: show only what matches

The run mode decides what happens to the model before the rules run:

  • Reset model (default) — clears all earlier colours, opacity and hiding first, as Reset all does. Every run starts from a clean model.
  • Append only — keeps what is already there and adds the rules on top.
  • Hide model — hides everything first. Only what the rules match is shown.
  1. Make a rule that finds what you want to see, for example contains HA-SAFE-ESCAPEROUTE, colour green.
  2. Open the run mode list and choose Hide model 1, then press Run. Only the escape routes are left on screen.
  3. To see the whole model again, press Reset all.

A rule with opacity 0 hides its items. This works in every mode, for example to remove one discipline from view.

Use a name from the model

You don't have to type names. Take them from the model tree or the 3D view.

  1. Click the item in the Hierarchy tree 1, or click it in the 3D view.
  2. In the filter row, press + 2. The name of the last selected item is put into Value 3. In Multi mode it is added as a new line, so you can collect several names one by one.

Paste a list of names, each with its own colour

With the match type Multi, the value is a list: one exact name per line. A colour after the name (separated by a space, tab or comma) colours that line only. Lines without a colour use the rule's colour.

  1. Set the match type to Multi 1. The value turns into a larger box 2.
  2. Paste the names, for example from a spreadsheet. A colour can be a name (red), a hex code (#2f9e44) or default to keep the original colour. Add :50 for 50 % opacity (red:50).
  3. Press Run. Here two speakers are red, one is green, and the one without a colour gets the rule's blue 3.

Combine filters: Append, Keep, Remove

A rule can have several filter rows (+ Add filter). They are worked through from top to bottom, and the first word of each row says how it combines with the rows above:

  • Append — add what this row finds.
  • Keep — of what the rows above found, keep only what this row also matches.
  • Remove — take what this row finds out again.

Example: colour the public-address loudspeakers, but only the A-side units.

  1. Append everything in the PA system: contains HA-TELE-PA at Lvl 3.
  2. Keep only the names that start with /SX-, the loudspeakers.
  3. Remove the names that end with B.
  4. The result of all three rows together.

Match types: Contains, Equals, Starts with, Ends with, Wildcard (use * anywhere, e.g. /SX-*-011*) and Multi (one exact name per line).

Save and reuse a rule set

  1. Press Save (ALT 1024). The browser downloads set-color-rules.json.
  2. Later, or on another computer, open Set Color and press Load (ALT 1025) to pick the file. It replaces the current rules.
  3. Press Run.

A rule's Store limits it to models loaded from one store. Use this when two stores have parts with the same names.
