User guide · App layout F5

Transform

Move, turn and resize parts of the model, for example to try out where a new piece of equipment fits. You make the items a transform object first; the app then keeps track of how far each object has been moved. Numbered markers on each picture match the numbers in the text; click a picture to see it full size.

On this page

App layout · F5

The Transform layout

Press F5 (or pick Transform on the App Layout ribbon) to switch to the transform workspace. Everything on its ribbon works on a transform object: select items in the tree or the 3D view, press New Object, then move, turn or resize the object with the buttons, or drag it with the handles in the 3D view. The list on the right shows every object and how far it has been moved. The model files themselves are never changed; see what is kept.

  1. Transform ribbon — described group by group below.
  2. Hierarchy — the model tree. Click a row to select that item and everything under it.
  3. 3D view — click an item to select it; the handles appear when the selection is an object.
  4. Console — minimised. Click its tab to see a line for each mode you switch on or off.
  5. Transform Objects — the list of objects; see The Transform Objects panel.

Ribbon

The Transform ribbon

The move, turn and resize buttons are greyed out until the selection is a transform object. Every change can be undone with Undo (ALT 101). This undo is separate from the colour Undo on the Selection Color ribbon.

Object

  1. New Object (ALT 131) — makes the selected items a transform object, named after the selected node. While the selection is an object the button is greyed out: that object is the current object, the one the rest of the ribbon moves. Its row is outlined in the list. A selection inside another object becomes its sub-object; see Move a part of something you have moved.

You can select something large in the tree and then deselect a few parts of it before pressing New Object: the object is then the large node without those parts, and its row says so (1 node(s), 3 left out). On a very large selection a short "working" message is shown while the object is made.

Selecting an object's items again, in the tree, the 3D view or with the select button on its row in the list, makes it the current object again. With a selection that is not an object nothing moves; press New Object first.

On/Off, Pivot and Options

  1. Move (ALT 110) — shows arrows on the current object in the 3D view. Drag an arrow to move the object along it.
  2. Rotate (ALT 111) — shows three rings. Drag a ring to turn the object around it. Hold Shift to turn in 15° steps.
  3. Scale (ALT 112) — shows a square handle on each arrow. Drag one to stretch or squeeze the object in that direction only.
  4. Set Pivot (ALT 120) — places the object's pivot by hand: the point that Rotate and Scale turn and resize around, and where the handles sit. It is the same pivot as on the object's row in the list: placing it here fills in the Pivot offset there. See Use a pivot. Once a pivot has been placed by hand, the button reads Adjust.
  5. Reset (ALT 121) — drops the hand-placed pivot: it goes back to the side picked under Pivot in the list, the centre unless you chose another.
  6. Auto Disable (ALT 1226, on at the start) — when you leave this ribbon (another ribbon tab, or another layout), the handles, pivot placing and Move To Click are switched off, so a later click in the 3D view does not move anything by accident. The app remembers this choice.

Press the lit Move, Rotate or Scale button again to hide the handles. The handles always point along the model's X (red), Y (green) and Z (blue) directions, even after you have turned the item. A drag counts as one step for Undo.

Placing the pivot

  1. Lock (ALT 127) — keeps the pivot where it is now, as the object's pivot. The object does not move.
  2. Cancel (ALT 128) — leaves the pivot where it was before you started.
  3. Item Pivot (ALT 122) — while it is on, click any item in the 3D view to put the pivot at that item's centre. The selection does not change.

Quick Move and Step

  1. Move To Click (ALT 130) — press it, then click a point on the model: the current object moves so that the middle of its underside sits on that point. Handy for putting equipment on a floor. It works once; clicking empty space cancels it.
  2. Unit — mm, cm or m for the step.
  3. Step (ALT 190 / ALT 191) — how far the Move buttons go, and how much Bigger / Smaller changes the size. − / + change it by 0.25.

Move, Scale and Rotate

  1. R, L, B, F, T, Bo (ALT 160 … ALT 165) — move the current object one step towards the right, left, back, front, top or bottom, the faces of the view cube. If you rename the cube's faces in Settings, the letters follow.
  2. Bigger (ALT 150) — makes the object bigger in all directions, so that its longest side grows by one step.
  3. Smaller (ALT 151) — the same, smaller.
  4. T→F and the other turn buttons (ALT 170 … ALT 175) — turn the object 90° so that the side that was on top faces front (T→F), back, left or right, or so that the front faces right (F→R) or left (F→L).

Bigger, Smaller and the turn buttons work around the object's pivot.

Reset, Objects and History

  1. Reset Obj (ALT 140) — puts the current object back where it was in the model file. The object stays in the list.
  2. Reset All (ALT 141) — puts every object back. The objects stay in the list.
  3. List (ALT 134) — shows or hides the Transform Objects panel. The button is lit while the panel is open.
  4. Undo (ALT 101) — undoes the last change: a move, turn, resize or reset, but also a new or deleted object and a number typed in the list.
  5. Redo (ALT 102) — does it again.

Panel

The Transform Objects panel

The list of every transform object. It opens with the F5 layout, from List on the ribbon, or with ALT 694. Objects are shown as a tree: a sub-object sits indented under the object it rides on.

  1. Objects & files — New Object (the same as on the ribbon), Save… (ALT 135) and Load… (ALT 136) for the whole list as a file, and Delete all (ALT 137). The two arrow buttons close (ALT 138) or open (ALT 139) every row of the list at once. This section stays in view; the list under it scrolls on its own.
  2. A row — the object's name and, in orange, how far it stands from its place in the model: the distance moved, the angle turned and the scale. at rest means it has not been moved.
  3. A sub-object — indented under its container. Its numbers are counted from the container, so they do not change when the container moves.
  4. Row buttons — select the object's items (which makes it the current object), mute it (ALT 132: show it where the model has it, keeping its numbers), reset it, and delete it (ALT 133). The keys work on the current object. A container also has a first button (ALT 142) that closes the rows of all its sub-objects, or opens them when none is open.
  5. Move, Rotate, Scale — the same numbers, to read or to type. Move is in metres, Rotate in degrees around X, Y and Z, Scale is a factor along the object's own length, width and height.
  6. Pivot — the point the numbers are counted around, and where the handles sit: the centre or the middle of one side of the object, plus an offset in metres. Changing it does not move the object.
  7. Rides on — the object this one follows. It is filled in when you make an object inside another. Clear it to make the object stand on its own, or pick any other object. Changing it does not move the object.
  8. Add selection (ALT 143) and Remove selection (ALT 144) — change what the object holds; see Fix what an object holds. To animation copies the object into the animation; see Use an object in an animation. On a container, the two arrow buttons at the right end of this line close (ALT 145) or open (ALT 146) the rows of all its sub-objects, like the pair in the top section does for the whole list.

Deleting an object puts its items back where the model has them. Its sub-objects stay where they are and ride on the object above it instead.

Step by step

Common tasks

Move an item by an exact distance

  1. Select it, here the loudspeaker /SX-HA86-011A, and press New Object.
  2. Set the Step, for example m and 1.00.
  3. Press T under Move to lift it one metre. Press again to go further, or Undo to take a step back. Its row in the list shows the total, and you can type an exact number there instead.

Drag an item into place

  1. Select it, press New Object, then Move under On/Off. Arrows appear on the object.
  2. Drag an arrow. The item follows while you drag and stays where you let go.
  3. To set it down on a floor or a beam instead, press Move To Click and click the spot.

Turn an item

  1. Select it, press New Object, then Rotate under On/Off.
  2. Drag a ring. Hold Shift to turn in 15° steps. For exact quarter turns, use the buttons under Rotate instead.

Move a part of something you have moved

Objects can sit inside each other. Move a whole skid, then adjust one valve on it:

  1. Select the container, here the group /HA-TELE-PA, press New Object and move it.
  2. Select one part inside it, here /SX-HA86-011A, and press New Object again. In the list the part appears indented under the container: it is a sub-object.
  3. Move the part. Only the part moves.
  4. Select the container's row in the list and move it. The part follows, keeping its own offset.

The order does not matter: an object made around a part you have already moved takes that part as its sub-object, without moving it. A selection that is half inside an object and half outside cannot be made an object; select inside the object, or all of it.

Fix what an object holds

If the first selection missed a part, or took one too many, you do not have to start again:

  1. Select only the items that are missing, or that should not be in the object.
  2. Open the object's row in the list and press Add selection or Remove selection.
  3. Added items take the object's place and numbers at once; removed items go back where the model has them. The object is selected again afterwards, ready to be moved.

The two keys work on the object you had selected last, so you can pick the object, select the extra items and press ALT 143 without opening the list. A change that would leave an item half in one object and half in another is refused.

Use an object in an animation

An object you have placed and given a pivot here can start an animation, so you do not set it up twice:

  1. Open the object's row in the list and press To animation (ALT 147).
  2. For a container, tick with sub-objects (ALT 148) to bring everything that rides on it along as sub-objects, or untick it to send the container alone — what rides on it is then left out of it.
  3. Switch to the Animation layout. The object is on the Timeline with the same items, pivot and parent, and one key at 0 s holding where you placed it. Add keys after it.

It is a copy: changing the transform object afterwards does not change the animation. A scale is not taken along, because animations do not scale. Brief for AI on the Animation ribbon lists your transform objects too, so an AI writing the animation uses the objects you picked instead of guessing them.

Use a pivot

By default an object turns around its own middle. To turn a valve around its flange, or a hatch around its hinge, either pick a side under Pivot on its row in the list, or place a pivot by hand:

  1. Select the object and press Set Pivot. Dashed arrows and an orange marker appear on the object's pivot.
  2. Drag the arrows to move the marker to where the item should turn. Or switch on Item Pivot and click another item to put the pivot at its centre.
  3. Press Lock. Rotate, Scale, Bigger, Smaller and the 90° buttons now work around the pivot, and the object's row in the list shows it as the Pivot offset.
  4. The pivot belongs to the object and is kept, also when you select something else and come back. Press Reset in the Pivot group to drop it.

Put everything back

Undo steps back one change at a time. Reset Obj puts the current object back in its original place in one go, and Reset All does that for every object. Resets can be undone too. To see an object in its original place for a moment without losing its numbers, mute it in the list.

Good to know

What is kept, and what is exported

  • Moves only change what you see in TreDeSpace. The model files are not changed.
  • Moves are not kept when you reload the page, and viewpoints do not store them.
  • To keep the objects, press Save… in the Transform Objects panel. The file holds every object: its items by name, its numbers and what it rides on. Load… brings them back, also after the model has been imported again.
  • The objects stay when a model is unloaded and loaded again; they find their items by name.
  • While you animate (the Animation layout) every object is shown in its original place and cannot be moved or edited: the panel shows a notice and its fields are greyed out, and so are New Object and the step buttons on the ribbon. Everything comes back when you leave the animation.
  • To keep only where the items are, save a state snapshot in the Export panel (open it from the Panel tab of the ribbon or with CTRL+E) with Save transforms ticked. Loading the snapshot later puts the items back where you moved them, but as loose items: it replaces the placement and empties the object list.
  • Exports from the Export panel (GLB, IFC and TDP) write the items where they are now, moved, turned and resized.
  • Selecting, and measuring afterwards, work on the items where they are now. Labels and measurements you made before the move stay where they were.
