How it behaves

      
    
        
  • Column types are detected. A column where every value SQLite returns is a number gets the number operators and its 123 tag. Everything else is text. No setup in the report.
    • 
        
  • Number columns have the operator button on the left and the value right-aligned, in line with the numbers below.
    • 
        
  • Paste from Excel. Pasting several cells (a copied column, or a row) into any filter makes it an in-list filter: one value per cell, empty cells skipped, repeats dropped. A not-in-list filter stays not-in-list.
    • 
        
  • List editor. An in-list filter opens a resizable box with one value per line, where you can read, type or paste values. The count shows repeats, and the table follows as you type. Done, Esc or a click outside closes it. The filter cell then shows the values separated by ;.
    • 
        
  • Text compare ignores capitals and surrounding spaces, as today.
    • 
        
  • Shortcuts while typing. Starting a filter with >, >=, <, <=, != or <> switches the operator and removes the sign. Old habits keep working.
    • 
        
  • The button turns blue when a column uses anything other than its default. The cell gets a blue underline while it filters.
    • 
        
  • Filters in several columns must all match. Export, copy and "With selection" act on the rows shown, as today.
    • 
        
  • Keyboard: Alt+↓ in a filter opens its operators, Esc closes the list.
    •

    •
